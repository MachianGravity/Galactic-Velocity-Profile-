Model velocity vs Observed velocity plot

https://github.com/MachianGravity/Galactic-Velocity-Profile-/tree/main/Velocity_Profiles/

The illustration depicts the Machian Gravity (MG) fitting applied to the SPARC galaxy dataset. The green line with error bars, show the observed velocities from the SPARC dataset. The blue dotted curve represents the velocity computed using Newtonian mechanics based on the baryonic matter, while the solid red curve reflects the velocity computed using the Machian gravity model. I have also shown the velocity profile using MOND and the NFW model in yellow and violet dashed curve to provide a comperative analysis.

$$a_{\text{obs}}=\frac{a_{\text{bar}}}{1-e^{-\sqrt{a_{\text{bar}}/a_{0}}}}\;\qquad\qquad\qquad\qquad \text{Parameter: }\qquad a_0$$

Machian Gravity Formula:

$$v^2=\frac{GM}{r}\left[1+\left(\sqrt{\frac{M_c}{M}} - 1\right)\left(1-e^{-\lambda r}\left(1+\lambda r\right)\right)\right]\;\qquad\qquad\qquad\qquad \text{Parameter:} \qquad M_c, \lambda^{-1}$$

NFW Profile:

$$v^2 = 4\pi G \rho_s r_s^3 (log(1 + x) - x/(1 + x))/ r\;\qquad\qquad\qquad\qquad \text{where}\qquad x=\frac{r}{r_s} \;\qquad\qquad\qquad\qquad \text{Parameter:}\qquad r_s, \rho_s$$
